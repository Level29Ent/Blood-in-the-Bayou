# Gameplay screenshot / civilian vehicle avoidance repair

Evidence: the reported screenshot shows bright square atmospheric particles and dark rows of cloud lobes. `polish.js` rendered daytime dust using an untextured PointsMaterial; its square point sprites explain the visible floating squares. `downtown.js` used Lambert-lit spherical cloud lobes in an evenly spaced line, producing dark segmented undersides. Daytime motes are now hidden, remaining night fireflies use a radial alpha map with smaller size/opacity, and scene changes release owned mote resources. Clouds use a pale unlit transparent material, flattened overlapping irregular lobes and no depth writing. This is a targeted cleanup, not a photoreal replacement of the game's stylized environment or NPC meshes.

Collision reproduction: the base `prologue-crowd.advance` moved residents directly between walkable cells, never checking dynamic vehicles. A baseline fixture walking between two street points crossed a parked vehicle's oriented footprint. The new pedestrian-vehicles helper uses oriented spec.len/spec.wid ground-plane bounds expanded by pedestrian radius, sampled movement sweeps and local detour corners. It checks static walls before movement and resolves a car moving onto a waiting resident to a safe non-wall side. Boats, removed vehicles and different elevations are ignored; wrecks that remain present still block. Resident nav cells advance only on actual arrival, not on a blocked step.

The prologue director passes nearby traffic (filtered once per animation update) and wall collision into resident advance, including panic movement. Waiting residents are also separated from car overlaps. This specifically repairs ambient resident traffic interaction; no universal physics engine, vehicle braking, new collision damage or blanket rewrite of every scripted stationary NPC is claimed. Player/vehicle/combat collision behavior and mission rewards are not changed. Full moving-traffic edge cases and physical-device performance require gameplay verification.

`/game/pedestrian-vehicle-review.html` is a signed-out isolated production-algorithm regression with proxy car/person geometry and restart/rotate-car controls, not a full-city appearance test.
