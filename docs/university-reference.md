# Bayou State University reference-inspired redesign

The existing NOLA university campus keeps its four rooms (administration, science, arts, library), parcel, front-facing openings, central circulation and survival-story lab target. Its shells now use warm sandstone/red brick, narrow mullioned lancet windows, pointed trim, buttresses, crenellated parapets and finials. Administration has a brick clock tower, pale upper belfry and slate spire inspired by the supplied collegiate architecture rather than a copied institution. The lawn and crossing paths remain. Library side furniture gets orange lounge accents and timber coffer details on its original footprint.

The separate, existing classroom venue used by the quiz, Ahmad meeting/escort and supply pickup now has tiered side-bank lecture scenery, blue seats, laptops/notebooks, a projection panel/chalkboard, side lectern, glass lobby partitions, orange lounge benches and wood ceiling panels/drum fixtures. Original entrance/service coordinates remain. A flat 44-unit center aisle leaves the service and scientist/gear points clear. The side tiers are blocked furniture, not navigable elevations. No new walkable atrium floor, escalator mechanic, enrollments, NPC crowd, copied branding or quiz changes are introduced. Decorative upper-frontage details are roof-owned along with the ceiling so existing roof reveal behavior remains supported. Existing street-frontage rotation handles the authored furniture as usual.

Original furniture replaces generic classroom desks and skips generic stock/checkout/finish passes for classroom only. New art uses shared geometry/material instances with no external models/textures, dependencies, real-time lights or animation loops. Existing campus shell meshes remain instanced. Other landmarks and legacy university fallback shell remain unchanged.

`/game/university-review.html` loads the production campus and actual-size classroom builders with quad/Gothic-hall/lecture/lobby review views. It is not full-city gameplay or physical mobile-device verification. Tests cover multiple hall sizes, route/service/gear clearance, finite bounded geometry, campus four-room identity and taller clock-spire, script order/overlay exclusions, actual classroom branch execution and roof-child world transforms, alongside existing prologue and NOLA tests. Full-city escort/capture/quiz and mobile GPU performance still need deployed checking. This is a stylized procedural interpretation, not a photo scan or exact campus reproduction.
