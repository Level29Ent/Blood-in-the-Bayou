# Creole Travel Center truck-stop refit

Existing diner/truck-stop venue receives stocked travel racks, chrome wheel/accessory wall, cream/red booths, counter equipment, red/silver entrance accents and an original blue globe-style rooftop marker. Original Creole Travel Center branding is used rather than Iowa 80 or Love's logos. Forty boxed travel products and seven wheel displays are shared procedural instances. Existing lot, entrance, diner service location and interactions remain; no fuel purchase mechanic, working pumps or drivable trucks added.

An optional lit red/yellow canopy with pumps/bollards uses the old decorative forecourt area only when the full envelope clears roads, water, buildings and protected plots at lowland height. It is omitted on rotated frontages or blocked lots, rather than overriding road access. Parked trucks are intentionally not added because actual-site turning clearance is not verified. The existing diner shell and original services remain, generic duplicate props/stock/finishes are skipped for this venue only.

Shared instances and static canopy panels add no external assets, dependencies, actual lights or extra update loops. Original globe is a simple generic geometric sign; art is stylized rather than photographic reconstruction. Tests cover service/entry clearance, stock counts/no lights, finite transforms, no-op blocked forecourts, loader/overlay integration and execution of the production diner branch on rotated frontage. Full-world forecourt availability, site driving and rendered appearance/mobile performance require deployed checking.
