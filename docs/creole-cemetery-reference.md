# Creole above-ground cemetery

Existing cemetery features receive dense but navigable rows of New Orleans-inspired above-ground tombs: pale stucco, aged gray stone, exposed brick patches/streaks, sealed framed tablets, layered cornices, gabled and barrel-vault forms, crosses/spires and modest flower/vase offerings. No real family names or inscriptions copied. The central grass/gravel lane, south gate and row gaps remain open; layout scales to each existing parcel. No added palms because their ground clearance and existing mission approaches are not verified.

Original cemetery placement/reservation, map footprint, entrance and perimeter collision remain. New tomb blockers share the production layout; the old twelve identical cuboid tombs and old solid-looking fence meshes are replaced, while perimeter blocker bounds stay. New open spear-style fence art has the same south opening. No new crypt interiors, underground navigation, corpse models or gameplay/mission rules.

Shared procedural geometry/materials, no external images/models, dependencies, actual lights or update loops. Static weathering is modeled color/trim, not a dynamic decay effect or photo scan. `/game/cemetery-review.html` uses actual production builder on a labeled sample parcel, with overview/lane/tomb cameras; not full-city or device verification. Tests cover several parcel sizes, shared blocker bounds/central route, finite no-light geometry, loader order and production collider wiring; existing reservation regressions remain. Full-world appearance, gate/tomb traversal and mobile-GPU performance need a deployed preview.
