# Reference military base camp

Existing military base receives six static tan canvas tents, four parked low-poly aircraft, four parked armored display vehicles, two static modeled U.S. flags, small tent-side utility boxes, paved service strips and a hangar-style segmented motor-pool door. Reference aircraft storage rows, canvas camp and armored motor pool inspire original shapes, not copies of a real installation or tactical layout. Display aircraft/armor are scenery only, not new drivable/flyable vehicles, weapons, inventory or troop spawning.

Original parcel relocation, four service buildings/barracks, gate, Powell command/formation positions, eight troops and alternating commands remain. New scenery sites are filtered against existing buildings, formation area, range and medic footprints. Sites add matching military collision blockers; troop path planning now considers these blockers as well as buildings. The 26-unit patrol perimeter remains clear. Existing civilian activities, base operations, marksman course, field medic and mission points are untouched. No new training/tactical mechanics, live munitions or model weapon behavior are added.

Static shared geometry/material instances add no external models/images, dependencies, real-time lights, extra animation loops or downloads. Flags use red/white stripes, blue canton and simple white star dots as modeled art, not a waving simulation. Existing troop animation is retained. New props follow the actual relocated base coordinates. Original-size 768×768 fixture tests verify model bounds, collision placement, service-point clearance and all eight soldier routes to four patrol destinations; deployment/full-world verification is still required.

Overview/tents/aircraft/motor-pool cameras review static art only, not the complete barracks model, active troops, operations or physical mobile-device performance. This is a stylized procedural interpretation, not photographic reconstruction.
