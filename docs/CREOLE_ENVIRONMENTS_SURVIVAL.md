# Creole environments, docks and survival

Original procedural game assets remain active. This integrates regional detail into the current world and reuses existing navigation, ammunition, ballistic/melee detection and blood/impact effects. It does not add a second combat engine or promise universal 60fps.

## Locations and interactions

- New Tremé cottages gain black balcony balusters/rails, brick alley edges, shared warm emissive lantern cores and historic-style street labels. Lanterns do not allocate PointLights. The street labels use the game's existing sign renderer, not an exact historical plaque reproduction.
- Existing Natchez shrimp pier receives stacked cargo and a small grass levee-like mound beside its approach. U at the captain loading spot awards $150 game cash with a three-minute active-play cooldown; full trawling remains the existing captain job. This is a loading interaction, not a crate physics job. The Natchez keeps its existing paddle-wheel movement/boat controls; no geographic Mississippi re-route is claimed.
- City Park lagoon gets a timber plank dock, pylons, two pontoon slips and cleats. U near the dock sign boards a procedural skiff; exit returns to the dock. Its small protected lagoon limits navigation. Boat collision still excludes docks and land. Lightweight wave shader overlays the lagoon, no extra reflection target.
- A separate safe288×320 deep-bayou parcel has murky animated water,18 cypress-like trunk/canopy groups and moss strips,3 solid stilt shack exteriors and one open-front juke room. Elevated plank routes connect them. The existing juke joint and new room share the existing radio/audio system; sign amplitude reads an AnalyserNode from the existing master bus. No microphone/autoplay/second audio player; external iframe music is not readable by this analyser. This is stylized vegetation/geometry, not scanned cypress assets.
- Enter Bank Sublevels appears inside the existing bank: two concrete/steel rooms, circular doors and rotating wheels, deposit racks, laser control, per-floor once-only $1250 cache, lift and return. U at center control releases lasers/doors; U at cash collects; U at right rear changes floor; U at rear center returns. Only active floor visible. Loot records saved separately without resetting campaign. This is an optional exploration cache, not a full cinematic robbery/pursuit simulation.
- Existing Corner Grocer receives shelves/goods, cooler, counter/register, neon and a separate Bodega Checkout panel. Meals use game cash and check max HP; ammo only for an already-owned pistol. Generic property and cashier/looting behavior remain separate.
- First non-private safehouse gets workshop and supply props, one-session medkit/owned pistol ammo interaction and an explicit three-wave defense button. Existing rest/save services remain. Repair near door with U; zombies attack the barricade proxy, stay outside, and use existing AI/combat. Four enemies per wave; completion pays$2100, ammo and heal, failure pays nothing. Event enemy bodies use six instanced part batches capped12; original entity hitpoints/navigation/corpses unchanged. Other enemies retain their existing rigs. This is not a universal horde renderer replacement.

## Performance

Repeated small props use shared instanced batches. New static batches use frustum culling; individual instances cannot be occlusion-culled by that flag. Event zombies are selected within600units with a12-instance cap (batch culling disabled because it changes each frame). Low retains existing disabled shadows/postprocessing; higher shadow resolutions and KTX2 manager/production concrete, wood and fabric maps remain from earlier changes. This patch doesn't convert every legacy texture or material to KTX2/PBR. No new high-resolution textures, dynamic regional lamps or planar reflection cameras. Physics/update and shader/frame-time measurements on a real iPhone remain required.

## Checks

Unit tests cover bounded regional geometry, finite deck metadata, wave progression/failure, vault loot once-only, bodega purchase guards, event instance caps, and actual vault control/loot/exit wrapper. Source-world checks separately exercise City Park boarding/exit, bank entry/loot/return and street connectivity. GPU review `/game/creole-survival-review.html` uses shared regional/vault builders, not full-world placement proof. Native ZIP refreshed, not compiled/signed. No claim all requested high-end graphics, continuous water reflections, universal compressed textures or stable60fps are complete.
