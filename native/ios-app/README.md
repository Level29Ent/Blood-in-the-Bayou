# Blood in the Bayou — maintained iOS host

Restored from the owner's Capacitor ZIP. **`public/game` remains the game source
of truth.** Never edit `www` or `ios/App/App/public`: both are generated by sync.
The native AdMob bundle is injected only in this app, not into the website.

## Build / test on a Mac

From the repository root (Node + pnpm + Xcode required):

```sh
pnpm install --frozen-lockfile
pnpm ios:sync
```

Open `native/ios-app/ios/App/App.xcodeproj`, select your Apple signing team and a
physical iPhone, then build. `cap sync` regenerates the local SPM paths and plugin
registration. Do not add a second Google Mobile Ads SDK: the pinned
`@capacitor-community/admob` plugin already supplies it and UMP. Xcode must resolve
and compile the Swift packages; Linux JS checks cannot verify this.

On the first Enter City / Continue click, the app resolves UMP consent before
initializing/loading ads. Consent failure does not prevent play. **Ad privacy**
opens UMP privacy options; leave multiplayer before using it. Configure the
app's Privacy & messaging in AdMob (including UMP's IDFA message if tracking is
used); there is no separate, duplicate ATT prompt in this code.

## Release gate

`src/config.json` contains the owner's public iOS app and interstitial IDs.
`testMode: true` substitutes Google's iOS test interstitial in **all build types**
(including Release). A test build does not earn revenue.

Before changing it to `false`, verify on an iPhone:

- consent required/not required/denied/unavailable, privacy options and changed choices;
- shown ads, no fill, load errors, presentation failure, dismissal, expired preload;
- single mission start after dismissal; duplicate taps cannot start twice;
- no ad on launch, timed death/respawn, mission one, multiplayer, driving, or
  uncontrolled Spotify playback; at least three minutes between shown ads;
- game simulation/input and game audio stop for an ad and restore afterward;
- verified ad-free entitlements suppress ads if StoreKit is later integrated.

Then confirm app readiness in AdMob, current SKAdNetwork requirements, privacy
policy/App Privacy disclosures, age rating, policy compliance, signing and App
Store submission. StoreKit purchases are still **not implemented**.

Set `src/config.json` testMode to false only after those checks; do not use live
units for development. Rebuild/sync and upload a new signed iOS build. Deploying
the website does not update an installed app.

## Regenerate the download

```sh
pnpm ios:archive
```

Requires Python 3 for ZIP creation. Generates
`public/downloads/blood-in-the-bayou-ios.zip` with the current web game and the
native sources. The ZIP omits dependencies, signing files and duplicated staged
iOS web assets. Its README requires `npm install && npm run sync` before opening
Xcode; this regenerates Swift package paths for the recipient's machine.
The maintained lockfile/workspace remains the preferred build source.

References: [plugin](https://github.com/capacitor-community/admob/),
[Google iOS setup](https://developers.google.com/admob/ios/quick-start),
[interstitials](https://developers.google.com/admob/ios/interstitial).
